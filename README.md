# util-linux-notes(基于 util-linux 2.39.3)
这个repo主要储放我最近读的util-linux工具库里面的有些命令的源码阅读笔记。在这个AI霸行的世界，其实知识的获取非常便捷，但是这只是给我们的学习带来了便利，不能完全依赖。AI给出的答案是零零散散的，作为一个学习者，希望这整个知识是成一定体系并且有一些逻辑的，并且夹杂个人的理解，记录下来会便于翻阅。
笔记的方向主要分为以下几点：
1. 搞清楚这个命令是为了在内核里做什么(主要不是读内核代码，这一块会比较粗略)。
2. util里面的流程是怎么设计的，有什么主要功能。
3. 会多focus到有调用到内核函数的地方
